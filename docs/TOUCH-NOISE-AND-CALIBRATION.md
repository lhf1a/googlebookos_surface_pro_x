## 2026-11-03：用户确认驱动的完整向导（v4，取代下文 v3 采点限制）

固定顺序：打开后5秒倒计时 → 12秒静置检测 → 生成本机补丁 → 用户导出候选文件／临时应用 →
再次静置检测 → 用户确认静置效果和正常触摸 → 保存本机规则并进入坐标校准 →
拇指10轮采集 → 按证据生成候选 → 同条件10轮复测 → 用户确认与最终保存。

### 静置补丁独立保存及复测

原有 SPXNOISE1 稀疏插值、SPXNOISE2 有界窄带插值和 SQ2 四格保护保持。
`noise-export` 校验设备身份后只导出数据文件；Android 系统文件选择器允许用户保存 `.noise`。
导出不等于激活或验收。`noise-retest` 保持当前 active 规则，继续观察原始热图，
应用全屏窗口同时计数输出的新触点。原始噪声持续而输出触点减少是不同指标；
窗口计数不是全系统 evdev 认证，no_data 不会写成“正常”。
坐标候选/撤销会重启 IPTSd：助手在重启前发布 `reload`，重启后要求新 nonce 的 ACK，避免新进程丢失已确认的静置补丁或重放旧 learn。
规则只有用户长按确认才 `noise-save`；未保存预览180秒自动恢复。过期预览拒绝假装仍在生效复测。

当前通用算法只为多窗口证据支持的稀疏尖峰／有限窄带生成补丁；广域、边缘无双侧支持、
交叉或短暂异常不会伪造安全屏蔽规则。坏带信息丢失时，内部真触摸仍可能点不到。
新流程不将这类情况隐藏成“完全修复”，允许重测、退出或用户明确接受限制。

### 坐标采集不再划屏蔽区，也不限制距目标的偏移

每次轨迹取分轴中位数，其他 pointer 的抬起不消费该样本；42次采样仍按目标顺序配对。
为避免大偏移落点被屏幕“跳过按钮”吞掉，采样全屏不设置触摸操作区；音量减跳过该点，
音量加重采上一个采样。尚未做实机大偏移采样验收。

`Calibration.fitAxis` 按重复采样分歧加权、合并重叠输入位置，并用 PAVA 单调回归和极小
单调正则避免反折。不因一对分歧使整组无效；取消原8%校正上限以及最终5点2.5%误差作废。
Java、root profile validator 与实际 IPTSd 曲线解析器同步支持大偏移。
保留身份、有限值、0..1输出、严格单调、端点及格式校验；“无限检测范围”指不限制距目标的

候选不是自动激活：应用先说明范围和失触风险，长按才允许180秒预览，可恢复原规则，
只有用户确认正常触摸后才保存。空间信息已丢失的坏带不可能凭算法还原任意真实触点；
完全落在坏带内的手指仍可能无法点击，必须保留区域跳过，不宣称全屏恢复正常。

### 校准采集：按目标/指针归属，隔离连续鬼点

静置期间应用只观察并吞掉自身窗口内的触摸，不让鬼点点击重试/应用/保存按钮。
从真实 Android 坐标建立32×32三窗口占用图，不假定热图行就是旋转后的屏幕Y。
重复出现的局部干扰区加一格邻域保护，以红色显示，只用于排除校准样本，不禁用系统触摸。
扩展后超过18%屏幕则拒绝自动采点，而不是屏蔽大半屏或输出假校准。

每个目标仅接收±10%局部框内的新落指，并持有该 pointer ID；目标外的连续鬼点、
其它指针的抬起不再导致真实手指整次失败。目标内多个有效触点视为歧义，拒绝本次。
需要至少80ms稳定按住、位移不超过2.5%、在1500ms内抬起才接收；变绿提示在抬手前出现。
这些门限只作用于校准采样，不添加系统触摸延迟。短鬼点不触发跳过；屏幕跳过需按住400ms，
仍支持物理音量减。不可用区域两次采样一并置空、沿用原曲线锚点，不伪造成功样本。

候选验证区分主机确定性回归、真实日志回放与实机预览；二进制构建成功不等于实机缓解或
正常点击/拖动/双指通过。当前启动分区不自动更新，RAM部署状态另记于私有验证记录。
