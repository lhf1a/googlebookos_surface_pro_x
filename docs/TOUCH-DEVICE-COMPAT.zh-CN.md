# Surface Pro X 触控构建适配

## 支持的触控设备 ID

启动触控助手（`touch-services` 与输入节点刷新）同时支持以下 SPI HID 设备 ID：
- `045E:0C21`（SQ2）
- `045E:0996`（SQ1）

`build-source-boot` 显式打包全部四个触控助手。设备 ID 适配与幽灵触控开关相互独立：`--ghost-touch-fix off` 仅关闭连续性补丁与四格热图补丁，不影响双机型的触控启动。

回归测试：

```sh
python3 tests/test_surface_touch_device_ids.py
```

## SQ2 热图处理开销优化

`patch-iptsd-sq2-heatmap.py` 不再每帧复制 46×68 个 double（25,024 字节），而是保存四个候选结果并在全部读取完成后写回，同时对低于 `239/255` 的候选跳过邻域采集和中位数计算。

- 设备/尺寸限定（`045E:0C21`、`46×68`）、阈值、四点位置及原始邻域语义保持不变。
- 连续性补丁对首个稳定接触立即上报、消失或无效时立即释放，不稳定样本则保留上一稳定位置。
